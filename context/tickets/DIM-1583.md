```
cd ~/dimos                         # never from $HOME: a cyclonedds checkout there shadows the package
export LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libgomp.so.1
ROBOT_IP=192.168.123.161 .venv/bin/dimos --rerun-open none --rerun-host 0.0.0.0 --no-build-native run unitree-go2-mls-htc

export DIMOS_POINTLIO_LIDAR_IP=192.168.1.171 DIMOS_MID360_LIDAR_IP=192.168.1.171 DIMOS_POINTLIO_HOST_IP=192.168.1.100 LIDAR_HOST_IP=192.168.1.100
ROBOT_IP=192.168.123.161 .venv/bin/dimos --transport lcm --rerun-open none --rerun-host 0.0.0.0 --no-build-native run unitree-go2-nav-3d
```

## Watch for

- Jeff's `~/dimos/.env` pins `ROBOT_IP=10.0.0.99` through pydantic dotenv, even without direnv. An
  explicit `ROBOT_IP=` on the command line wins.
- The Orin's `enP8p1s0` is static `192.168.123.100` (+ `10.21.31.50` for the M20), the same
  address as the dev box's `g1-wired` profile. On a shared link only IPv6 link-local SSH works.
- Zenoh logs `Unable to send Hello ... to 10.0.0.73`: that is the dev box's `spy` scouting. Noise.
- Jeff left a loop that builds `rimos-recorder` whenever no cargo build is running. CPU competition.
- On the G1 run `voxel_ray_tracing` alone held 177% CPU (DIM-1502). Watch `uptime` on nav-3d.
