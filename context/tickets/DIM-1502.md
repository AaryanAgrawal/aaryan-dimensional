## Context

Pim has only tested it in sim and asked for someone to run it on the actual G1. The PR body is not
written yet. +2740 lines across 9 files: a `g1_sonic_wbc_task` (task, pipeline, streamed motion,
zmq wire), the `unitree_g1_sonic_wbc` blueprint, a `sonic` LFS asset, and a touch to
`mujoco_sim_module.py`.

## Watch for

- It is a whole-body torque controller, so the first hardware run should be on the gantry with the
  e-stop. Same hazard class as groot-wbc.
- If it follows groot's shape it will release sport mode at connect, which drops a standing robot
  while the policy is unarmed. Check before running on the floor.
- Same environment gotchas as DIM-1494: LCM network fixes do not survive reboot, and the open3d
  static-TLS failure will hit any stack that decodes pointclouds on the Jetson.
