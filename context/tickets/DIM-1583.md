## Run on the Go2

```
ssh dimensional@<jetson>          # wifi 10.0.0.83; eth link-local in credentials.md
cd ~/dimos
export LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libgomp.so.1
ROBOT_IP=192.168.123.161 .venv/bin/dimos --rerun-open none --rerun-host 0.0.0.0 --no-build-native run unitree-go2-mls-htc
```

- Onboard L1 only, no extra hardware: `unitree-go2-mls-htc` (VoxelGridMapper + MLS + DanLocalPlanner
  + DanHolonomicTC). Mid-360 rig: `unitree-go2-nav-3d` (Point-LIO + RayTracingVoxelMap + MLS +
  BasicPathFollower); the lidar goes on the Orin's second port `enP1p1s0`, 192.168.1.x, IPs via
  `DIMOS_POINTLIO_LIDAR_IP` / host IP (Jeff's `~/dimos/.env` has his values).
- Viewer from the laptop: `dimos-viewer --connect rerun+http://<jetson-ip>:9877/proxy --ws-url ws://<jetson-ip>:3030/ws`.
- Wired Go2 is `192.168.123.161`; on wifi find it with `dimos go2tool discover`.

- Jeff's `~/dimos/.env` pins `ROBOT_IP=10.0.0.99` through pydantic dotenv, even without direnv. An
  explicit `ROBOT_IP=` on the command line wins.

  address as the dev box's `g1-wired` profile. On a shared link only IPv6 link-local SSH works.
